# 序棠顾问工作室

虚构精品皮具品牌的中文微信话术工具。技术方案为 FastAPI、React、TypeScript、LangGraph 和 SQLite。

当前已接入模型设置、话术工作台、在线测试、历史评估、DeepEval 自动评测及 Excel 导出。LangGraph 编排联系意愿检查、资料准备、模型生成和输出校验；SQLite 保存产品、案例、运行、批次快照、手动评价及独立自动评测实验。

首页为话术工作台；设置页可直接访问 [模型设置](http://127.0.0.1:8000/#settings)，历史页可访问 [生成历史](http://127.0.0.1:8000/#history)。

## 本机运行

需要 Python 3.13+、uv 和 Node.js 20.19+（或 22.13+）。前端目录提供 `.nvmrc`；若使用 nvm，请先执行 `nvm use`。执行 `node --version` 确认当前终端使用正确版本。

在项目根目录安装后端依赖：

```bash
uv sync
```

构建前端：

```bash
cd frontend
nvm use
npm ci
npm run build
cd ..
```

如果未使用 nvm，可省略 `nvm use`，但仍需满足 Node 版本要求。

启动应用：

```bash
uv run uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

浏览器打开 [本机工作室](http://127.0.0.1:8000)。前端构建完成后再启动后端，后端将同时提供网页和 API。

开发前端时，可在第二个终端执行：

```bash
cd frontend
npm run dev
```

访问终端显示的地址，前端会将 `/api` 请求转发至本机 8000 端口。

## 模型配置

默认服务地址为 `https://api.deepseek.com`，默认模型为 `deepseek-flash`。默认值依据 [DeepSeek 官方文档](https://api-docs.deepseek.com/) 于 2026-11-08 核实，模型名称可修改。

- 可在启动应用的终端设置 `export DEEPSEEK_API_KEY='你的密钥'`，也可在页面输入 API Key；页面仅显示是否已配置，不回传明文。
- 密钥优先使用页面输入或已保存的值；没有保存值时读取环境变量。环境变量中的密钥不会因保存设置而写入配置文件，修改环境变量后需重启应用。
- 密钥留空表示继续使用已保存的密钥。
- “测试连接”调用当前表单指定的模型，沿用已保存密钥，但不会隐式保存表单。
- 测试会产生实际 API 请求，可能收费；超时为 60 秒，不自动重复调用。
- “保存配置”独立于连接测试：保存成功不表示模型已验证可用。
- 配置保存在根目录 `config.local.json`，其中密钥为本机明文，文件已被 Git 忽略。需要清除密钥时可关闭应用并删除该文件，重启后恢复默认配置。
- 本工具按单机本地运行设计，勿直接将该服务暴露到公网。

### OpenCode Go 预设

在模型设置的“服务预设”中选择 OpenCode Go，会填入以下配置：

- 服务地址：`https://opencode.ai/inference/go/openai/v1`（SDK 自动追加 `/chat/completions`）。
- 模型示例：`glm-5.3-flash`，可以改成账户实际可用且支持相应接口的模型。
- API Key：手动填写 OpenCode Console 的密钥；切换到 OpenCode 不会沿用 DeepSeek 文件或环境密钥。

OpenCode 请求使用真实客户端标识 `xutang-advisor/0.1` 和当前独立生成请求的会话头。每次生成是独立单次对话，不隐含跨请求会话记忆。

官方 Go 面向编码 Agent 流量，本工具是话术应用；使用前需确认套餐适用范围。通用应用可考虑 Console 按量付费接口。本轮已使用用户配置的 Go 账户及 `deepseek-v4.1-flash` 实际完成两轮固定集，不代表其他账户、套餐或模型一定可用。[Go 说明](https://opencode.ai/docs/console/go)、[接口及会话要求](https://opencode.ai/docs/console/harnesses)。

## 话术生成与历史

1. 在模型设置页填入并保存有效配置。
2. 工作台选择场景，输入客户信息、对话历史、联系意愿及场景补充；可选择目录产品，或显式载入虚构示例。
3. 正常生成提供三条中文候选，可选择和复制。格式检查不等于事实及语气审核，使用前需要顾问复核。
4. 客户刚提出拒联时，通过规则提供三条确认回复，并明确标记未调用模型；此前已拒联且对话结束时停止生成。这两种情况无需模型密钥。
5. 生成成功、停止生成和可预期失败均保存到 SQLite；模型失败不会用模板冒充成功。原始无效模型输出也会保留以供排查。
6. 历史记录包含输入、产品、品牌规则、场景指引、模型及提示词版本的当次快照。页面切换保留工作台草稿，刷新浏览器会重新开始编辑；已生成历史仍保留。

产品初始资料见 [虚构产品目录](backend/data/products.json)，当前品牌表达及完整候选要求见 [v2 提示词](backend/prompts/v2.md)，保留 [v1 基线](backend/prompts/v1.md)。尺寸、重量、颜色和保养资料均为虚构初稿，供审阅。首次运行写入根目录 `xutang.sqlite3`；已初始化的商品不会被种子文件覆盖。

SQLite 保存业务历史，不作为 LangGraph checkpoint；每次生成独立运行，不隐含跨请求聊天记忆。API 的实际输入输出可查看 [本机接口文档](http://127.0.0.1:8000/docs)。

## 在线测试

打开 [在线测试](http://127.0.0.1:8000/#testing)。固定输入来自 [50 例数据](backend/data/test_cases_v1.json)，版本 `cases-v1`：产品推荐和价格异议各 9 例，其他四场景各 8 例。

“场景模拟”提供聊天式交互：选择案例并编辑虚构客户、场景资料、相关产品及初始对话；由使用者扮演客户输入消息，生成三条候选，选择一条加入对话后继续下一轮。每次生成发送完整对话并保存运行快照；模拟会话切换页面仍保留，刷新会重新开始。客户刚提出拒联时手动选择对应联系状态，采用确认回复后结束模拟。工具不会自动发送微信。

- 单例测试加载案例的编辑副本，修改后运行不会覆盖固定输入；实际提交内容及输出保存在历史中。
- 批量测试使用固定 50 例，冻结启动时的模型配置和品牌提示词，串行调用与工作台相同的生成入口，每例完成后保存进度。
- 批次记录包含案例、模型、提示词版本和结果关联。可查看每例输出、原始无效输出及错误原因；“生成成功”只是结构检查通过，不等于质量合格。
- 页面刷新或切换后，重新进入批量页即可查看已保存记录。单例失败不阻止其余案例继续运行。
- 当前使用单个本机应用进程执行任务，同时只运行一个批次。应用停止或重启时标记为中断，保留已完成案例；重新运行会创建新批次，不自动续跑。
- 未配置密钥时启动批次会报错，不创建虚假的运行记录。正式 50 例需要配置可用服务后实际运行；自动测试的模拟结果不用于提交。

## 评估、比较与导出

打开 [历史与评估](http://127.0.0.1:8000/#history)，按场景、提示词版本或批次筛选；列表、统计与导出使用相同范围，包含全部匹配记录。

- 对每条候选选择合格、不合格或未评估；不合格须写明原因。另行评价三条切入点是否有差异，缺乏差异须填写原因。
- 人工复核与 AI 初评分别保存。AI 初评由评价者手动录入已有结果，不自动调用模型，也不视为人工结论。同来源再次保存会更新该评价，不修改生成快照。
- 单条合格、案例可用、整组达标分别统计：至少一条合格即案例可用；三条均合格且有差异才整组达标。以当前范围全部已生成话术或案例为分母，同时展示未评估数。未评估不算合格；生成失败及停止另列。
- “同输入结果对比”直接匹配完整业务输入及产品快照，展示两次输出与提示词快照。提示词、品牌规则或模型变化不会改写旧记录；比较不自动证明质量提高。更新提示词时须同步修改 `backend/workflow.py` 的 `PROMPT_VERSION` 并使用对应提示词文件。
- “导出筛选结果 Excel”提供案例结果、评价记录、统计、批次说明及口径说明。包含完整输入、资料快照、三条输出、错误及结果版本，不读取配置密钥。超出 Excel 单元格上限的字段在“长文本”表按运行 ID、字段及来源分段保留，可按序拼接。
- 运行中的批次只导出已保存结果，完成数量见批次说明；正式提交前应确认 50 例完整运行并完成必要复核。自动测试中的话术和评价均不属于正式提交结果。

## 运行结果与架构

正式测试以 OpenCode Go 的 `deepseek-v4.1-flash` 在相同的 50 个固定输入上执行 v1 和 v2；人工复核与自动评测独立保存。评审模型与生成模型相同，且未经人工校准；未评项不计为质量合格或不合格。完整报告与案例表随交付材料提供。
